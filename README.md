# Nostalgia-Revival-Light-Saber-Toy
A CAD design project for the Half Life Event
So when I was younger I had this plastic light saber from the Star Wars franchise which could extend and collapse the saber laser back from/into the hilt. This was a very cool feature and one of my favorite toys growing up so I decided, since the original product is long gone after having grown, I should design a 3D printable replica to revive this old memory.
